# Eter

Sintonización de emisoras de radio libre de publicidad. App de radio por Internet para Android.

- **Stack**: Kotlin · Jetpack Compose (Material 3) · Media3 (ExoPlayer + MediaSessionService) · Room · Retrofit/OkHttp
- **API**: Radio Browser (listado público de emisoras)
- **Sin cuentas, sin anuncios, sin servidor propio.**
